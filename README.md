# Portfolio

Minimal portfolio for Ashutosh Sao, built with Next.js, React, Tailwind CSS, and Bun.

## Getting Started

Install dependencies and run the development server:

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Checks

```bash
bun run lint
./node_modules/.bin/tsc --noEmit --incremental false
bun run build
```

## Stack

- Next.js App Router
- React
- Tailwind CSS
- Framer Motion
- React Activity Calendar
